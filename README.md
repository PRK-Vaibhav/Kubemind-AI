# KubeMind AI

AI-powered Kubernetes Intelligence & Observability Platform.

## Features

- Real-time Kubernetes pod monitoring
- Live CPU and memory metrics
- FastAPI backend integration
- React observability dashboard
- Kubernetes Metrics Server integration
- Recharts live visualization
- Auto-refresh monitoring system

## Tech Stack

### Frontend
- React.js
- Vite
- TailwindCSS
- Recharts

### Backend
- FastAPI
- Kubernetes Python Client

### Infrastructure
- Docker Desktop
- Minikube
- Kubernetes

## Architecture

Kubernetes Cluster
↓
Metrics Server
↓
FastAPI Backend
↓
REST APIs
↓
React Dashboard

## APIs

### /pods
Returns pod information.

### /metrics
Returns CPU and memory metrics.
